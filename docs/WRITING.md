# Writing the handbook

- Plain, direct English. Short sentences. Say what to do, then why if it is not obvious.
- One page per topic. Seven pages is the target; add a section before you add a page.
- Give the exact command or setting. Prefer a table over paragraphs for "situation → action".
- Put `title` and `description` in frontmatter. No body-level `#` heading.
- When a page or heading moves, add the old path to the new page's `redirectFrom`.
- Write only what a maintainer or agent needs to act. No history, no process for its own sake.
