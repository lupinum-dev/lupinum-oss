# Security policy

## Supported versions

Security fixes go into the newest release line: the npm `latest` tag, or the
`next` tag while the package has no stable 1.0 release yet. Older versions do
not receive fixes; upgrade to the newest release on that line.

## Reporting a vulnerability

Do not open a public issue. Report the vulnerability privately through
[GitHub private vulnerability reporting](https://github.com/{{REPOSITORY}}/security/advisories/new).
Include the affected versions, the impact and steps to reproduce. We aim to acknowledge
reports within a week.
