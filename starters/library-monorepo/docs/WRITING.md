# Writing public documentation

Use Lupinum Controlled English, based on ASD-STE100. Do not claim formal certification.

- Use sentence-case headings.
- Use active voice and short sentences.
- Put one main instruction in each sentence.
- Explain concrete outcomes.
- Define necessary technical terms.
- Use labeled code fences.
- Keep examples complete and current.

Verify commands and links before you merge a documentation change.
