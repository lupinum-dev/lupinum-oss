# Contributing

Open an issue before a non-trivial change. Keep pull requests small and within one clear package responsibility. Explain the result, verification, release note, and risk. Run `pnpm verify` before review.

For a public package change, run `pnpm changeset`. Select the affected packages,
choose the change level, and describe the user-visible result. Commit the Changeset
with the change. Do not assign package versions manually.
