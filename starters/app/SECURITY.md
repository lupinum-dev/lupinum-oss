# Security policy

## Supported versions

Only the current production deployment at [{{DOMAIN}}](https://{{DOMAIN}}) receives fixes.

## Reporting a vulnerability

Do not open a public issue. Report the vulnerability privately through
[GitHub private vulnerability reporting](https://github.com/{{REPOSITORY}}/security/advisories/new).
Include the impact and steps to reproduce, but no production secrets. We aim to
acknowledge reports within a week.
