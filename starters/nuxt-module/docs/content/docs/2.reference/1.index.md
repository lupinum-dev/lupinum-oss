## Module options

Set them under `{{CONFIG_KEY}}` in `nuxt.config.ts`.

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `greeting` | `string` | `'Hello'` | The word `useGreeting()` puts before the name. |

## `useGreeting(name)`

Auto-imported. Returns the greeting for `name`, for example `Hello, World.`

| Parameter | Type | Meaning |
| --- | --- | --- |
| `name` | `string` | Who to greet. |
