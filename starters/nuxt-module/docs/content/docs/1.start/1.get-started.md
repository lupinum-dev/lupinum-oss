## Install

```bash
pnpm add {{PACKAGE_NAME}}
```

Add the module to `nuxt.config.ts`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['{{PACKAGE_NAME}}'],
})
```

## Use the composable

`useGreeting()` is auto-imported:

```vue [app/app.vue]
<script setup lang="ts">
const greeting = useGreeting('World')
</script>

<template>
  <p>{{ greeting }}</p>
</template>
```

## Check it

Run `pnpm dev` and open the app. The page shows `Hello, World.`
